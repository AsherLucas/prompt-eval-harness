# Security Policy

## Supported Versions

We support the latest minor release only. Older releases may not receive
security fixes; please upgrade to the latest release first.

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.
Instead, report it via GitHub Security Advisories on this repository
(Security tab > Report a vulnerability), or open an issue only if it
contains no sensitive details.

We will acknowledge receipt, assess the report, and publish a fix and
release notes when a fix is available. Please allow reasonable time
for assessment before public disclosure.
